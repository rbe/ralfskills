# ralfskills

This repository is the skill collection. `CLAUDE.md` is the only entry file.

Stages, in order: `r-plan`, `r-develop`, `r-review`, `r-release`. Other skills: `r-record`, `r-project-report`, `r-project-setup`, `r-github-pipeline`, `r-onboard`, `r-system-state-report`, `r-board-merge-report`, `r-board-merge`, `r-skills-review`, `r-component-upgrade`. Language skills: `r-node`, `r-python`, `r-shell`, `r-jvm`, `r-go`. Subskills `r-plan` asks and `r-review` checks: `r-security`, `r-privacy`, `r-ux-ui-design`, `r-api-design`, `r-observability`, `r-performance`. A project skill is an extra name listed here. If `CLAUDE.md` lists a project skill `<project>-<stage>`, the stage reads it after its own steps. The addendum holds only what is true for that project.

A row of `docs/requirements/*.md` is a requirement. Its status is `planned` (open) or `in force` (a rule that holds).

The general rules, the Agents section, and the communication contract stand once, in `skills/r-project-setup/rules.md`. The next line imports that file. Do not copy it here.
