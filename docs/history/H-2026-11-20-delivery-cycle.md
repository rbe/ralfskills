# Complete the cycle, the decision records, and the requirements list

## Plan

`plan` was not invoked. The owner set the goal and could not be asked. The goal: a new or an existing project installs the skills with APM, the four stages deliver a fix or a feature, and the decisions are a record that agents follow and that converts to a document.

Boundary: the stages own their steps. `record` owns every board document, the ADR status, the closing of a task, and the decision log. `project-setup` owns the entry-file template. `project-report` owns the reading of test ids.

Pattern: a duty is a numbered step in the skill that owns it. A document a person reads is generated by a Make target.

Out of scope: a `test-changed` target for a Makefile on `sdlc.mk`. That is the Open row D-7.

## Develop

`release` has the steps that ship a slice: stop on a failed gate or an open finding, one branch, commit, push, CI, merge, and close. `record` closes a task. `develop` asks for the history file when `plan` did not run. `record` names the sections of an ADR body. `make decision-log` writes `build/decision-log.md`. `project-setup` writes `CLAUDE.md` from `templates/CLAUDE.md` when the file is missing. `make toon` fails when the name of a skill differs from its directory. The project report reads the id of a JavaScript, TypeScript, Java, Groovy, or Kotlin test from a comment, and it does not read a test inside an installed skill. `report.mk` gives a product repository the `project-report` command.

`docs/REQUIREMENTS.md` has the rows R-1 to R-64 with the columns Id, Title, and Statement. R-16 to R-52 are the owner's list, checked against the skills and corrected. R-57 to R-64 are new. The requirements index lists the id and the title.

Four contradictions between skills are removed. `security` and `privacy` name the same order as the skill index. `github-pipeline` names itself as the owner of the shipment rule. `SDLC_CI` has the default of `sdlc.mk`. The `.PHONY` list of `project-setup` is the list in `project.mk`. A divergence that is not a pipeline divergence is an ADR, not a Decided line.

Python and shell are the language skills.
