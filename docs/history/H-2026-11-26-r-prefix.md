# Every skill of the collection starts with r-

## Plan

On 2026-11-26 the owner chose the prefix `r-` for every skill, so a project can install skills of other collections without a name clash. `plan` was not invoked.

## Develop

[R-105](../requirements/collection.md#r-105) is the rule. Each of the 29 skill folders moved to `skills/r-<name>`, and references changed to match. Words that name a language or a command did not change. [R-28](../requirements/record.md#r-28) strips `r-` before it compares owners.

## Review

Gates ran: `make toon`, `make links`, and `make ids`. The entry-file word counts stayed at 847 and 917, as [R-76](../requirements/project-setup.md#r-76) states. A new test pins that each skill folder starts with `r-`.

## Release

The commit "Prefix every skill with r-" is on the working branch and is not pushed. A project that installs this collection sets `ref` to the new tag and renames the skills in its files.
