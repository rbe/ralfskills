# Every skill of the collection starts with r-

## Plan

On 2026-11-26 the owner chose the prefix `r-` for every skill of the collection, so that a project can install skills of other collections without a name clash. A project calls `/r-plan` instead of `/plan`. `plan` was not invoked.

## Develop

[R-105](../requirements/collection.md#r-105) is the rule. Each of the 29 folders under `skills/` moved with `git mv` to `skills/r-<name>`, and its `name` in the frontmatter is the new folder name. The pattern `upgrade-<language>-components` is now `r-upgrade-<language>-components`.

Each reference to a skill changed: the backticked names, the paths `.claude/skills/<name>/...` and `../<name>/...` in the makefiles, the templates, the scripts, and the tests, the lists in `CLAUDE.md` and in its template, the tables and the `apm.yml` sample of the README, the requirement rows, the `description` lines, the `skills:` examples of `r-record`, and the labels of the two diagrams. `project_report.py` reads the skills `r-plan`, `r-review`, `r-develop`, `r-release`, and `r-project-setup`. A word that names a language, a file kind, or a command, such as `go`, `python`, or `gofmt`, did not change. A Make target keeps its name. The files in `docs/requirements/` keep the bare name of their owner skill, because the history files link to them. The test of [R-28](../requirements/record.md#r-28) strips `r-` from the folder name before it compares the owner. The history files before this one are a record of the past and keep the old names.

`skills.mk` derives no skill name: `apm install` copies each folder of the collection, so the installed folder is `.claude/skills/r-<name>/`. A project updates its `apm.yml`, its `CLAUDE.md`, and each Makefile include of `.claude/skills/<name>/...`.

The new test in `skills/r-project-report/scripts/test_project_report.py` names `id: R-105`. It asserts that each folder under `skills/` starts with `r-` and that its `name` equals the folder name.

## Review

The results are in the reply of the task. `CLAUDE.md` and its template keep their word counts, 847 and 917, because a backticked name stays one word. The limits of [R-76](../requirements/project-setup.md#r-76) did not change.

security, privacy, ux-ui-design, api-design, observability, performance: not touched.

## Release

The commit "Prefix every skill with r-" is on the branch of the task and is not pushed. A project that installs this collection takes the change as a new version: it sets `ref` to the new tag, runs `make skills-update`, then renames the names in its `CLAUDE.md`, its `apm.yml`, and its Makefile includes.
