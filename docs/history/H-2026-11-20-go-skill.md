# Add the Go language skill that a real project needs

## Plan

`plan` was not invoked. The owner chose the repository `rbe/gh-sweep` for a trial on a real project. That project is written in Go. APM installed the skills there, and the skill index listed no language skill for a `.go` file. `develop` stops in that case, so the collection could not develop that project.

Boundary: `go` owns the Makefile of a Go project and the rules for Go. `project-report` owns the script that reads the Go cover profiles.

Pattern: the same as for `python`, `node`, and `jvm`. One template fills every command variable. One script writes the coverage map and the file diff-cover reads.

## Develop

`go` is a language skill for `.go`, `go.mod`, and `go.sum`. `templates/Makefile.golang` runs Go in Podman, with gofmt, `go vet`, the tests, the coverage report, and the changed tests. The template has no `.go` ending, because gofmt and the Go tools read every file with that ending. `go_cover_map.py` reads one cover profile for each package. It writes the coverage map and a Cobertura file. The project report reads the `id:` comment of a `_test.go` file.

Python and shell are the language skills.

## Review

Every gate passed through Make in Podman with the pinned default images: `make format`, `make lint`, `make test`, `make integration`, `make editorconfig`, `make coverage`, `make test-changed`, `make ids`, `make toon`, `make project-report`, and `make decision-log`.

The Go template ran on a copy of the real code of `rbe/gh-sweep` in Podman. `make setup`, `make format`, `make lint`, `make test`, `make build`, `make coverage`, and `make test-changed` passed. After a change to one file, the diff report named the new lines that no test ran, and `make test-changed` selected the one package that covers the file. `make project-report` failed there, as it must: the five test files of that project name no requirement yet.

security: no listener, no secret, no personal data in a fixture. The template passes no token to the container.

privacy: no personal data.

ux-ui-design: no screen.

api-design: not HTTP. Not a module export.

The repository `rbe/gh-sweep` itself was then onboarded on a local branch, with the skills installed by APM from this branch. The project keeps its own way to run Go in a container. Its Makefile got the command variables and the include. Five Decided rows state what its test files prove, and two ADRs record rules the project already follows. One of them is a divergence: the project also accepts Docker. All thirteen Make targets passed there in Podman: `setup`, `format`, `lint`, `test`, `integration`, `editorconfig`, `build`, `coverage`, `test-changed`, `toon`, `ids`, `project-report`, and `decision-log`. The trial found one defect: the EditorConfig template asked for spaces in a Go file. The template now leaves the layout of a Go file to gofmt.

No finding. Left alone: the push of that branch. This session cannot push to `rbe/gh-sweep`, so the onboarding is a patch file for the owner. The fourth trial round stopped on the usage limit of the account and is not part of this history.
