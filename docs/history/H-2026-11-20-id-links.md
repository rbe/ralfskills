# Each id in a document is a link

## Plan

The slice: each id in running text of a document is a link. Out of scope: frontmatter, table id cells, tests, and skills. [R-27](../requirements/record.md#r-27) says a document does not build a path to another document. Decided row D-12 records the owner's choice.

## Develop

`links.py` in `record` finds each id that a table row or frontmatter defines. `make links` writes the links, and `make links-check` fails when a document would change. [R-69](../requirements/record.md#r-69) is the new requirement. The examples `[D-9](../DECISIONS.md#d-9)` and `[ADR-0001](../adr/ADR-0001.md)` in code spans stay text.

## Review

Gates passed in Podman, including `make links-check`. A second `make links` changed no file. Finding, fixed here: the tool removed a link inside a code span. The test `test_a_link_in_a_code_span_or_a_code_block_is_an_example_and_stays` proves the fix.

## Release

The branch is pushed. This slice does not merge it.
