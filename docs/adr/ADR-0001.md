# A test names the requirement it proves

A test carries `id:` in its header or metadata. That line is the one `record` matches. The id is a roadmap id, a known-issue id, an ADR id, or a decision id. The test name states what the system does when that requirement holds. A test with no id fails review. The id is not a path.
