# Requirements of ux-ui-design

The rows that the skill `ux-ui-design` owns. `collection.md` says what the status means.

| Id | Title | Status | Statement |
| --- | --- | --- | --- |
| <a id="r-33"></a>R-33 | Interaction questions | in force | `ux-ui-design` applies when the change has a screen, a control, or a visual. It is interaction only. Tokens, the type scale, and the component catalogue are product catalogues, as [R-52](collection.md#r-52) says. `plan` asks three questions. What does the person do, in one sentence? What does the empty state show, and what does the error state show? Can a keyboard reach every control a pointer can reach? `review` checks three things. The screen matches the answers, including the empty state and the error state. Focus is visible, and contrast holds for the text the person must read. A token that belongs to one product was not copied into this skill. This applies to both, when the skill is installed. `ux-ui-design` owns the questions. |
