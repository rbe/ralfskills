# Requirements of performance

The rows that the skill `r-performance` owns. `collection.md` says what the status means.

| Id | Title | Status | Statement |
| --- | --- | --- | --- |
| <a id="r-103"></a>R-103 | Performance questions | in force | `r-performance` applies when the change reads, parses, imports, or aggregates data, or claims a gain in speed, size, or quality. `r-plan` asks for the largest input, the number of reads of each file or row, and where the aggregation runs. `r-review` checks that data is read once and that a claim has a measured baseline from the same session. This applies to both, when the skill is installed, and `r-performance` owns the questions. |
