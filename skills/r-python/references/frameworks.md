# Frameworks

A framework this skill learns later is a file in this directory, named by the framework. `CLAUDE.md` names it. Read that file when the change uses the framework. The `r-python` skill and the stage skill still apply.

Django, Flask, and FastAPI have no file here yet. Do not invent a second lifecycle for them. A framework command that needs Python runs through `$(PYTHON)` in a Make target, as this skill says.
